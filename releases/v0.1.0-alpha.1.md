# v0.1.0-alpha.1 — MuJoCo SLAM（发布草案）

状态：待发布，未创建标签或 GitHub Release。

首次候选范围为 X2 全身仿真与 FAST-LIO 建图集成、校正时间单位修复、PCD 合并工具和验证输出。
运行入口：`bash simulation/mujoco/run_x2.sh --duration 20 --check`。
依赖 Ubuntu/ROS 2 Humble、已编译的本仓库消息与建图包、厂商 X2 模型/MC/MuJoCo 运行环境、X11 和用户扫描地图。
安装步骤与参数见 [仿真说明](../simulation/mujoco/README.md)。

验证：20 秒测试收到 200 帧雷达，保存 36,434 点，仿真位置 RMSE 4.01 cm；
MuJoCo/RViz 短测及四项回归测试通过。详见 [验证记录](../docs/validation/2026-10-29.md)。

兼容性：消息定义已匹配当前安装的 SDK，旧版消息消费者须核对接口并重新构建。
限制：光学扫描环境加平地接触，无扫描障碍碰撞、该场景的 Nav2 避障或真机导航验收。
地图与厂商二进制不包含在源码包中。
